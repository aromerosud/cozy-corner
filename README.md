# Cozy Corner

## WDD430 – Web Full-Stack Development

### Project Overview

Cozy Corner is a customizable student dashboard designed to help students organize their academic activities and develop productive study habits.

The application aims to provide a personalized workspace where students can manage their classes, track assignments, organize notes, and monitor their study routines in a comfortable and engaging environment.

### Planned Features

The planned features for Cozy Corner include:

- **Class Schedule:** Organize and view class schedules.
- **Assignment Tracking:** Manage academic assignments and deadlines.
- **Notes:** Create and organize class notes and quick notes.
- **Study Streaks:** Track study consistency and progress.
- **Study Tools:** Use hydration reminders and break timers.
- **Personalization:** Customize the dashboard with themes and profile settings.

### Technology Stack

- **Framework:** Next.js
- **UI Library:** React
- **Programming Language:** TypeScript
- **Styling:** Tailwind CSS

## Getting Started

### Prerequisites

Make sure you have Node.js and npm installed.

### Installation

Clone the repository and install the project dependencies:

```bash
git clone https://github.com/aromerosud/cozy-corner.git
cd cozy-corner
npm install
```
### Run the Development Server

Start the local development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

The application automatically updates as you make changes to the source files.
